# 游戏代练商城 - uni-app小程序

## 项目说明

这是游戏代练商城的uni-app小程序端，包含客户端和打手端两个角色的完整功能。

## 技术栈

- **框架**: uni-app (Vue 2)
- **UI**: 原生组件
- **HTTP**: uni.request 封装
- **状态管理**: 本地存储

## 配置说明

### 1. API地址配置

修改 `config/api.js` 中的 `BASE_URL`：

```javascript
// const BASE_URL = 'http://localhost:8000'  // 开发环境
const BASE_URL = 'https://your-domain.com'  // 生产环境
```

### 2. 微信小程序配置

修改 `manifest.json` 中的 `mp-weixin.appid`：

```json
"mp-weixin": {
  "appid": "你的小程序AppID",
  "setting": {
    "urlCheck": false
  }
}
```

## 运行说明

### 开发环境

1. **安装依赖**（如果需要）
   ```bash
   npm install
   ```

2. **运行到微信小程序**

3. **运行到H5**
   ```bash

   ```

4. **运行到App**
   - 使用 HBuilderX 打开项目
   - 点击"运行" -> "运行到手机或模拟器"

1. **发行到微信小程序**
   - 使用 HBuilderX 打开项目
   - 点击"发行" -> "小程序-微信"
   - 上传到微信小程序后台

2. **发行到H5**
   ```bash
   npm run build:h5
   ```

## 接口对接说明

### 认证方式

所有需要认证的接口都使用 JWT Token：

```javascript
// 请求头
Authorization: Bearer {token}
```

Token 存储在本地存储中：
```javascript
uni.getStorageSync('token')
```

### 响应格式

成功响应：
```json
{
  "code": 2000,
  "msg": "success",
  "data": {}
}
```

错误响应：
```json
{
  "code": 4000,
  "msg": "错误信息",
  "data": null
}
```

### 分页参数

```javascript
{
  page: 1,           // 页码
  page_size: 10      // 每页数量
}
```

响应：
```json
{
  "count": 100,
  "next": "http://...",
  "previous": null,
  "results": []
}
```

## 注意事项

1. **登录功能**
   - 当前登录页面是示例，需要根据实际的登录接口调整
   - 登录成功后需要保存 token 和用户信息

2. **图片上传**
   - 需要实现图片上传功能（充值截图、护航账号截图等）
   - 使用 `uni.uploadFile` API

3. **实时通信**
   - 聊天功能需要使用 WebSocket 实现实时消息推送
   - 可以使用 `uni.connectSocket` API

4. **权限管理**
   - 客户端和打手端使用不同的 tabBar
   - 需要根据用户角色动态切换

5. **错误处理**
   - 所有接口调用都需要添加 try-catch
   - 401 错误自动跳转登录页
